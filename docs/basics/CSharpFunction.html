编码（将字符串以某种形式存储为二进制）:
    ASCII (American Standard Code for Information Interchange):
        美国信息交换标准代码，使用7位二进制数表示256个字符。
    Unicode:
        一种标准，用于表示世界上大多数书面语言的字符，使用不同长度的编码点（如UTF-8, UTF-16等）。
    UTF-8 (Unicode Transformation Format - 8-bit):
        一种将Unicode字符编码为8位字节序列的格式。
    UTF-16 (Unicode Transformation Format - 16-bit):
        一种将Unicode字符编码为16位字节序列的格式。
    UTF-32 (Unicode Transformation Format - 32-bit):
        一种将Unicode字符编码为32位字节序列的格式，每个字符固定占用4个字节。
    EBCDIC (Extended Binary-Coded Decimal Interchange Code):
        一种主要用于IBM大型机系统的字符编码。
    GB2312/GBK/GB18030:
        用于中文字符的编码标准，GB2312是最早的版本，GBK是其扩展，GB18030是最新的版本。
    Big5:
        一种用于繁体中文的字符编码。
    Shift-JIS (Shifting Japanese Information Standards):
        一种用于日文的字符编码。
    ISO 8859:
        一系列用于表示拉丁字母、希腊字母、西里尔字母等的单字节编码标准。
    Base64:
        一种用64个字符表示二进制数据的编码方法，常用于在文本格式中传输二进制数据。
    URL编码:
        一种将URL中的特殊字符转换为可打印ASCII字符的编码方式。
    MIME (Multipurpose Internet Mail Extensions):
        一种标准，用于定义消息的类型和编码方式，用于电子邮件和网页传输。
    UU编码:
        一种将二进制数据转换为可打印ASCII字符的编码方法，用于在文本环境中传输二进制文件。
    YAML, JSON, XML:
        这些不是传统意义上的编码，而是数据序列化格式，用于在不同系统之间交换数据。

冒泡排序​

    就是将一个数组中的元素按照从大到小，或者从小到大的顺序进行排列
    示例：
        数组按照顺序排列
        int[] newnums = new int[] { 9, 8, 7, 6, 5, 4, 3, 2, 1, 0 };
    
        第一趟比较：8765432109，交换了9次，最大的数字9被放到了数组的最后 i=0 j=newnums.Length-1-0
        第二趟比较：7654321089，交换了8次，第二大的数字8被放到了倒数第二个位置 i=1 j=newnums.Length-1-1
        第三趟比较：6543210789，交换了7次，第三大的数字7被放到了倒数第三个位置 i=2 j=newnums.Length-1-2
        第四趟比较：5432106789，交换了6次，第四大的数字6被放到了倒数第四个位置
        第五趟比较：4321056789，交换了5次，第五大的数字5被放到了倒数第五个位置
        第六趟比较：3210456789，交换了4次，第六大的数字4被放到了倒数第六个位置
        第七趟比较：2103456789，交换了3次，第七大的数字3被放到了倒数第七个位置
        第八趟比较：1023456789，交换了2次，第八大的数字2被放到了倒数第八个位置
        第九趟比较：0123456789，交换了1次，最小的数字0被放到了数组的最开始
    
    可以使用Array.Sort(数组)进行数组的排列
        但是Array.Sort(数组)只能升序排列
        使用Array.Reverse(数组)只能将数组倒置，不能进行倒序
        先使用Array.Sort(数组)升序排列，再使用Array.Reverse(数组)就可以使数组降序排列

out参数的使用​

高级参数：out

  • 示例：求一个数组中最大值、最小值、总和、平均值
  • 如果在一个方法中，返回多个类型相同的值时，可以考虑返回一个数组
  • 但是，如果方法中有不同类型值时，数组就会受限制
  • 使用 out 参数，就可以在一个方法中，返回多个不同类型的值
    • out 参数要求在方法的内部必须为其赋值
    • out 参数在调用时，需要定义一个相同类型的接收参数
      通过该参数获取 out 中返回结果

语法：

// 没有返回值
public static void xxx(int[] par1, out int[] outpar1, out string[] outpar2) { }

// 调用
int[] xxx1 = new int[] { };
string[] xxx2 = new string[] { };
xxx(numArr, out xxx1, out xxx2);
// 遍历数组，将 xxx1 和 xxx2 中的值输出
// 有返回值
public static [type] xxx(string par1, string par2, out string outpar1) { }

// 调用
string xxx = "";
[type] 变量 = isLogin("test", "test", out xxx);
Console.Write(xxx);    // 输出 out 参数在 xxx 方法中的返回值
Console.Write(变量);   // 输出接收方法的返回值

方法的重载​

方法的重载就是指方法的名称相同，但是参数不同

  • 重载的好处是可以传入多种类型参数
  • 参数不同分为两种情况：
    1. 如果参数的个数相同，那么参数的类型就不能相同
    2. 如果参数的类型相同，那么参数的个数就不能相同
  • 方法的重载与返回值没有关系（不严谨 Java、C++ 有所不同）

面向对象初级​

面向对象：

  1. 面向对象的三大特性：封装、继承、多态
  2. 封装：把客观事物封装成抽象的类（类就是一个模板，确定了对象应该具有的属性和方法）
    • 封装是将数据（属性）和行为（方法）捆绑在一起的过程。
    • 它隐藏了对象的内部状态和实现细节，只暴露出一个可以被外界访问的接口（IComparable）。
    • 封装提高了代码的安全性和易于维护性，因为对象的使用者不需要了解其内部工作原理
  3. 继承：继承是一种机制，允许一个类（称为子类或派生类）获得另一个类（称为基类或父类）的属性和方法
    • 这使得代码重用变得可能，并且可以创建层次结构。
    • 子类可以扩展或修改基类的行为，但通常不能违反基类的封装性
  4. 多态：多态是指允许不同类的对象对同一消息做出响应的能力，但具体响应的动作取决于对象的实际类型
    • 这通常通过使用接口（IComparable）或抽象类以及重载和重写方法来实现。
    • 多态使得代码更加灵活，能够处理不同类型的对象，而不需要修改调用它们的代码

对象是根据类创建出来的

注意：结构不具备面向对象的特征，而类才具备面向对象的特征

属性​

属性存在的作用就是用来保护字段合法性，对字段得到赋值和取值进行限制

语法：


public string 属性名
{
    get { return 属性名; }
    set { 属性名 = value; }
}

属性本质就是两个方法，一个为 get 一个为 set

  • 当给属性赋值时，首先会执行 set 方法
    • 在 set 中判断的是 value 的值
  • 当输出属性值时，会指向 get 方法
    • 在 get 中判断的是字段的值

属性既有 set 也有 get，叫做可读可写属性

  • 只读或只写属性。只读属性没有 set 访问器，只写属性没有 get 访问器

字段是存储数据的，属性是调用数据的

字段需要使用 private（私有的），只能在当前类的内部访问

复习​

当创建好类的对象时，需要对类的对象中每个属性进行赋值，这个过程就叫做对象的初始化

静态和非静态​

语法：


public class MyClass
{
    public void Class1() {}
    public static void Class2() {}
}

区别：


public static class MyClass
{
    public static void Class1() {}
}

在非静态类中，既可以有静态类，也可以有非静态类（实例成员）

调用语法：

  1. 调用实例成员时，需要使用 对象名.实例成员
  2. 在调用静态成员时，需要使用 类名.静态成员名

总结：

  • 静态成员必须使用类名去调用，而实例成员使用对象名调用
  • 静态函数中，只能访问静态成员，不允许访问实例成员
  • 实例函数中，既可以使用静态成员，也可以使用实例成员
  • 静态类中只允许有静态成员，不允许出现实例成员
  • 静态类不能被实例化

应用：

  1. 如果类当作一个工具类去使用，则可以考虑将类写成静态类
  2. 静态类在整个项目中资源共享
    • 堆
    • 栈
    • 静态存储区域：静态类的资源
    • 遵循垃圾回收（GC - Garbage Collection）机制。当这些引用不再被任何地方使用时，垃圾回收器将自动释放它们占用的内存
    • 静态类在从程序全部结束后，静态类就会释放资源

构造函数​

构造方法用来创建对象，并且可以在构造函数中对对象进行初始化
作用：

  • 帮助初始化对象，给对象的每个属性依次赋值
  • 构造函数是一个特殊的方法
    • 构造函数没有返回值，连 void 也不能写
    • 构造函数的名称必须和类名一样
    • 创建对象的时候执行构造函数

关键字 new： 语法：


Person xxx = new Person();

new 做了三件事：

  • 在内存中开辟一块空间
  • 在开辟的空间中创建对象
  • 调用对象的构造函数进行初始化对象

构造函数可以重载
在类中，会有一个默认的无参数的构造函数，当产生一个新的构造函数之后，无论是否有参数，默认的无参数的构造函数都会被替换

this关键字​

  1. 代表当前类的对象
  2. 在类当中显示的调用本类的构造函数

析构函数​

语法：


~类名() {}

当程序结束的时候，析构函数才执行，帮助释放资源
使用析构函数会马上释放资源

面向对象初级总结​

  • 有一个距离属性（distance），这个属性是只读的，并且在构造方法中赋值。
  • 距离属性不能为负数。
  • 有一个价格属性（price），这个属性也是只读的。
  • 价格属性是根据距离属性计算的，计算方式是每公里 1 元。
    • 0-100 公里：票价不打折。
    • 101-200 公里：票价总额打 9.5 折。
    • 201-300 公里：票价总额打 9 折。
    • 300 公里以上：票价总额打 8 折。
